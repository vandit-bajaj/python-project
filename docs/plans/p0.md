# Phase 0 Plan: Foundations and Monorepo Skeleton

- **Phase**: 0 — Foundations and repo bootstrap
- **Author**: Lead Engineer
- **Status**: Pre-approved (conforms to Roadmap §9 Phase 0 and rules 00–70)

---

## 1. Objectives & Scope
Establish a production-grade, deployable, modular monorepo for DermaLens with zero-tolerance privacy enforcement, strict TypeScript standards, automated linting/formatting, mobile-first design tokens, CI guardrails, and architecture decision records.

---

## 2. Tasks & Deliverables

### A. Monorepo & Toolchain Setup
- Pin Node engine and package manager (`pnpm@12.x`) in root `package.json` and `.nvmrc`.
- Setup `pnpm-workspace.yaml` covering `apps/*` and `packages/*`.
- Configure `turbo.json` with cached build, test, lint, and typecheck pipelines.
- Configure `biome.json` for strict linting and formatting.
- Configure `.gitignore` with strict rules (no node_modules, no credentials, no real face images, no datasets, no zip files).
- Setup `lefthook.yml` and `commitlint.config.mjs` for conventional commit enforcement.

### B. Workspace Packages Skeleton
1. **`packages/analysis-core`**:
   - Pure TypeScript, zero React/DOM dependencies.
   - Exports `Analyzer`, `AnalysisResult`, `AnalyzerInput`, `RegionId` definitions.
   - Vitest suite verifying analyzer interface stub and pure calculations.
2. **`packages/ui`**:
   - Shared design system tokens (CSS variables: color palettes, spacing, typography, radii, safe area insets).
   - Base Tailwind/shadcn compatible definitions.
3. **`packages/models`**:
   - Typed manifests for versioned model and wasm assets.

### C. Application Skeleton (`apps/web`)
- Next.js App Router with React 19, strict TypeScript (`noUncheckedIndexedAccess`).
- Security headers & Content Security Policy (CSP):
  - `default-src 'self'`; `connect-src 'self'`; `worker-src 'self' blob:`; `img-src 'self' data: blob:`; `wasm-unsafe-eval`; `X-Robots-Tag: noindex`.
  - `Permissions-Policy: camera=(self), microphone=(), geolocation=()`.
- Base layout: `100dvh`, `viewport-fit=cover`, safe-area insets, neutral palette, thumb-friendly mobile buttons (>= 44px).
- Centralized English-only copy module: `apps/web/src/content/index.ts` (strictly cosmetic and non-diagnostic framing).

### D. Architecture Decision Records (`docs/adr/`)
- `0001-on-device-architecture.md`: Enforcing on-device analysis and strict CSP.
- `0002-analyzer-interface.md`: Standardizing pure UV-space analyzer contract.
- `0003-worker-boundary.md`: Offloading computation from main thread via Comlink.
- `0004-state-and-storage.md`: Local-first IndexedDB schema and client state strategy.

### E. Governance & Documentation
- `README.md`: Project purpose, non-diagnostic notice, All Rights Reserved notice.
- `LICENSE`: All Rights Reserved copyright notice (D12).
- `CONTRIBUTING.md`: Contribution policy and developer standards.
- `.github/pull_request_template.md`: Requiring perf/privacy impact and mobile viewport screenshots.

### F. Quality & CI Guardrails
- Vitest unit tests for packages and web components.
- Playwright E2E configuration with mobile viewports (iPhone 14 / Pixel 7).
- Automated **zero-outbound-requests** E2E test failing on any non-same-origin network request.
- Dependency licence gate (`scripts/check-licenses.mjs`): verifying all packages are permissive (MIT, Apache-2.0, BSD, ISC) and blocking GPL/AGPL.
- GitHub Actions workflow (`.github/workflows/ci.yml`) running all checks on PRs to `main`.

## 3. Risk Assessment & Mitigation

| Risk | Impact | Mitigation |
|---|---|---|
| Inadvertent external network request (CDN, font, analytics) | Breaks core privacy promise | Strict CSP + Playwright test monitoring network traffic on every run |
| Licence pollution from transitive dependencies | Breaks All Rights Reserved model (D12) | Automated licence gate script running in pre-commit and CI |
| Layout breakage on mobile devices with notches / home indicators | Degraded mobile UX | Safe area padding variables (`env(safe-area-inset-*)`) and `100dvh` in base layout |
| Desktop-first styling leakage | Poor thumb ergonomics | Design tokens and component tests default to 390px viewport width |
