# Phase 7 Plan — Local History and Progress

## 1. Overview & Objective
Implement a privacy-first, local-first data persistence and tracking layer in DermaLens using Dexie.js (IndexedDB). Enables users to track skin progress over time, compare scans side-by-side with delta metrics, export/import data via JSON, manage storage quota, and receive browser eviction alerts (specifically for iOS Safari 7-day eviction limits), with zero cloud servers or outbound requests.

---

## 2. Roadmap Requirements & Constraints

| Requirement | Implementation Strategy |
|---|---|
| **Dexie Schema & Versioned Migrations** | Dexie database `DermaLensDB` with versioned schema upgrades (`db.version(1)`, `db.version(2)`), strongly typed tables for `scans` and `settings`. |
| **Zod-Validated Schema Versioning** | `ScanRecordSchema` using Zod at read/write/import boundaries; records carry `schemaVersion: 1` and analyzer versions. |
| **Opt-in Thumbnail Storage** | Full-resolution photos are NEVER stored; low-res thumbnail is stored ONLY if user explicitly enables thumbnail opt-in switch. |
| **Timeline & Progress UI** | `/history` route featuring chronological scan cards, overall score badges, and quick trend indicators. |
| **Side-by-Side Compare & Delta Analysis** | Compare two selected scans side-by-side with numerical delta chips (e.g. `+5` or `-8`). Environmental drift warning when lighting/sharpness difference exceeds tolerance. |
| **Cross-Version Comparison Guard** | Visual flag/warning when comparing scans analyzed by different analyzer version releases. |
| **Storage Management & Safari Eviction** | Prominent JSON export/import round-trip; "Delete all my data" instant wipe; `navigator.storage.persist()` request; Safari 7-day eviction notice. |
| **Zero Network Access** | Entire storage layer runs client-side in browser IndexedDB; 0 outbound requests verified via Playwright audit. |

## 4. Risks & Mitigations
- **iOS Safari Storage Eviction**: Safari on iOS may silently evict site data if not visited in ~7 days.
  - *Mitigation*: Surface persistent advisory banner on iPhone advising regular JSON export, and invoke `navigator.storage.persist()`.
- **IndexedDB Incompatibility in Private / Incognito Windows**: Some browser private modes disable IndexedDB.
  - *Mitigation*: Wrap Dexie operations in try/catch and fallback to in-memory transient storage with user alert.
- **Corrupted User Import Data**: User could attempt to import modified or invalid JSON.
  - *Mitigation*: Strictly validate every imported record through `ScanRecordSchema` (Zod), discarding invalid payloads safely.
