## 1. Objectives & Scope
Implement the classical v1 blemish and acne candidate estimator in `@dermalens/analysis-core` behind the uniform `Analyzer` interface.
Provides transparent, explainable heuristic lesion detection with physical scale normalisation from iris landmarks, non-diagnostic cosmetic language ("estimated blemishes"), and a clean interface for an ML detector to drop in later.

Key Deliverables:
1. `AcneAnalyzer` implementing `Analyzer` in `packages/analysis-core/src/analyzers/acne.ts`.
2. Physical-scale blob / Difference-of-Gaussians (DoG) candidate detection at plausible lesion radii (1.5 mm – 4.5 mm diameter via `pixelsPerMm`).
3. Heuristic false-positive suppression:
   - Rejects specular highlights (high $L^*$, low chroma).
   - Rejects elongated linear structures (hairs, wrinkles) via eigenvalue / aspect ratio check.
   - Rejects flat dark spots without erythema halos (freckles, flat moles).
   - Rejects mask boundary edges.
4. Cosmetic classification:
   - Non-diagnostic severity bands: "Minimal" (0–2), "Mild" (3–10), "Moderate" (11–25), "Marked" (> 25).
   - Output includes estimated blemish count, regional density, UV-space lesion map, confidence, and metadata.
5. Per-skin-tone contrast adjustment and confidence scaling for Fitzpatrick IV–VI tones.
6. Worker pipeline integration in `apps/web/src/workers/vision.worker.ts`.
7. Dev visualizer update in `/debug/analyzers` with Playwright E2E tests and mobile screenshots.
8. Milestone 2 Report (`docs/reports/M2.md`).

## 3. Algorithm Details

### A. Combined Contrast & Erythema Saliency
A blemish or papule is characterized by:
1. Central elevated erythema: $\Delta a^*(x, y) = a^*(x, y) - \text{baseline}_a > 3.0$.
2. Localized circular peak: positive circular Difference-of-Gaussians response at scale $r \approx \text{pixelsPerMm} \times 1.2\text{ mm}$.

### B. False-Positive Suppression
- **Specular highlights**: If $L^* > 75$ and chroma $< 18$, reject (specular reflection from oil/lighting).
- **Elongated lines (hairs)**: Sample orthogonal cross-sections; if ratio of maximum to minimum gradient along orthogonal axes $> 2.4$, reject as a line.
- **Flat moles / freckles**: If local $L^*$ drops but $\Delta a^* \le 1.5$ (no erythema halo), reject.
- **Mask boundaries**: Points within 2 pixels of non-skin mask are rejected.

### C. Severity Banding (Non-Diagnostic)
- Count $\le 2$: "Minimal" (Score 0–15)
- Count $3–10$: "Mild" (Score 16–45)
- Count $11–25$: "Moderate" (Score 46–75)
- Count $> 25$: "Marked" (Score 76–100)

## 4. Test Plan
- **Synthetic Lesion Recovery** (`tests/acne.test.ts`):
  - Inject 0, 3, 8, 16 synthetic erythematous circular lesions into fixture.
  - Assert detected count is recovered within $\pm 1$.
  - Assert scores increase monotonically.
- **Suppression Verification**:
  - Inject specular highlight: count must remain 0.
  - Inject elongated dark line (hair): count must remain 0.
  - Inject dark spot without erythema: count must remain 0.
- **Per-Tone Validation**:
  - Test on Fitzpatrick II (fair) vs Fitzpatrick VI (deep).
  - Verify confidence is appropriately attenuated on deep skin where erythema contrast is lower, and no negative numbers or crashes occur.
- **Performance & Worker**:
  - Complete acne analyzer runs in $< 50$ ms on 128x128 fixture.
