- **Phase**: 3 — Analyzers v1 (classical CV)
- **Author**: Lead Engineer

---

## 1. Objectives & Scope
Implement the full suite of classical computer vision skin analyzers for DermaLens in `@dermalens/analysis-core` and wire them through the Web Worker pipeline.
Each analyzer evaluates a specific cosmetic concern on the canonical UV-unwrapped face texture, producing regional scores (0–100), a normalized UV heatmap, confidence derived from capture quality, and explicit versioning.

Analyzers are delivered in two tiers:
1. **Core Tier** (high confidence):
   - **Redness** (`redness`): Erythema detection via baseline-relative CIELAB `a*` elevation within the skin mask.
   - **Pigmentation** (`pigmentation`): Tone classification via Individual Typology Angle (ITA°) and dark-spot local contrast via Difference of Gaussians (DoG).
   - **Oiliness** (`oiliness`): Specular highlight detection (high $L^*$, low chroma $C^*$) with T-zone weighting.
   - **Texture / Pores** (`texture`): High-frequency energy filtering at physical millimetre scale using iris-derived `pixelsPerMm`.
2. **Beta Tier** (lower confidence):
   - **Wrinkles** (`wrinkles`): Directional ridge filtering in forehead and periorbital regions. Labeled beta with confidence capped at 0.70.
   - **Dark Circles** (`darkCircles`): Periorbital $L^*$ and chroma contrast compared against cheek baseline. Labeled beta with confidence capped at 0.75.

3. **Scoring Layer & Aggregation**:
   - Composite skin index aggregation, concern weighting, and confidence attenuation from `QualityReport`.
4. **Worker Integration & Benchmarks**:
   - Execute full analyzer suite off the main thread inside `vision.worker.ts` within the <= 3-4 s budget.

## 2. Technical Contracts & Types

### Input Specification
`AnalyzerInput` in `packages/analysis-core/src/types.ts`:
- `uvTextureBuffer: Uint8ClampedArray` (RGBA UV texture, e.g. 512x512)
- `width: number`, `height: number`
- `skinMaskBuffer: Uint8Array` (1 = skin, 0 = non-skin)
- `regionMasks: Record<FaceRegionId, Uint8Array>` (per-region binary mask)
- `pixelsPerMm: number` (iris-calibrated physical scale)
- `qualityReport: QualityReport` (lighting, blur, pose)
- Optional cached CIELAB buffers (`labL`, `labA`, `labB`) to avoid recomputation across analyzers.

### Output Specification
`AnalysisResult` in `packages/analysis-core/src/types.ts`:
- `id: string` (e.g. "redness")
- `version: string` (semantic version, e.g. "1.0.0")
- `overallScore: number` (0–100 relative index)
- `regionScores: Record<FaceRegionId, number>` (0–100 per region)
- `confidence: number` ([0, 1] derived from quality report)
- `uvMapWidth: number`, `uvMapHeight: number`
- `uvMapBuffer?: Uint8Array` (normalized 0–255 heatmap for 2D/3D visualization)
- `isBeta?: boolean` (true for wrinkles and dark circles)
- `metadata?: Record<string, string | number | boolean>` (e.g. ITA angle, dark spot count, specular fraction)

## 3. Analyzer Algorithms

### 1. Redness (`packages/analysis-core/src/analyzers/redness.ts`)
- **Method**: Convert to CIELAB; compute per-person baseline $a^*$ (median / mean) across valid skin pixels.
- Identify erythema pixels where $a^* > a^*_{\text{baseline}} + \Delta_{\text{thresh}}$.
- Region score combines affected area fraction and mean excess intensity:
  $$\text{Score} = \text{clamp}(100 \times (0.6 \times \text{areaRatio} + 0.4 \times \text{normalizedIntensity}), 0, 100)$$
- Heatmap: normalized $\Delta a^*$ clamped [0, 255].
- Confidence: `qualityReport.overallScore` penalized by color cast / warm lighting deviation.

### 2. Pigmentation (`packages/analysis-core/src/analyzers/pigmentation.ts`)
- **Method**: Compute Individual Typology Angle:
  $$\text{ITA}^\circ = \frac{\arctan((L^* - 50) / b^*) \times 180}{\pi}$$
  Classify Fitzpatrick tone proxy (Very Light to Dark).
- Detect local hyperpigmentation / dark spots using Difference of Gaussians (DoG) with kernel radii scaled to 1.5 mm – 3.5 mm via `pixelsPerMm`.
- Region score incorporates dark spot density and local contrast against skin baseline.
- Heatmap: DoG spot salience map normalized [0, 255].
- Confidence: baseline quality score, reduced if lighting evenness < 0.70.

### 3. Oiliness (`packages/analysis-core/src/analyzers/oiliness.ts`)
- **Method**: Specular highlight detection: skin pixels with high luminance ($L^* > 75$ or $> 80$ depending on skin tone baseline) and low chroma ($C^* = \sqrt{{a^*}^2 + {b^*}^2} < 18$).
- Weights T-Zone (forehead, nose, chin) with higher sebum clinical sensitivity.
- Score scales with specular pixel fraction and highlight intensity.
- Heatmap: specular intensity map [0, 255].
- Confidence: penalized if image is overexposed (`!qualityReport.exposureValid`).

### 4. Texture / Pores (`packages/analysis-core/src/analyzers/texture.ts`)
- **Method**: Discrete 2D Laplacian high-frequency filtering on $L^*$ channel at physical pore scale (0.3 mm – 1.0 mm kernel radius via `pixelsPerMm`).
- Calculates regional variance of high-frequency energy.
- Score represents relative surface roughness (0 = smooth, 100 = rough/enlarged pores).
- Heatmap: high-frequency magnitude map [0, 255].
- Confidence: strictly gated by `qualityReport.blurScore` (blur destroys high frequencies; drops to 0.2 if blurry).

### 5. Wrinkles (`packages/analysis-core/src/analyzers/wrinkles.ts`) [Beta]
- **Method**: Multi-directional ridge filtering (horizontal for forehead, multi-angle for under-eye / crow's feet) on $L^*$ channel.
- Regional line density and crease valley contrast.
- Marked with `isBeta: true`, confidence capped at 0.70; reduced if face yaw or pitch > 8°.
- Heatmap: ridge response map [0, 255].

### 6. Dark Circles (`packages/analysis-core/src/analyzers/darkCircles.ts`) [Beta]
- **Method**: Contrast between under-eye region (`FaceRegion.UNDER_EYES`) and adjacent cheek baseline (`LEFT_CHEEK`, `RIGHT_CHEEK`).
- Computes $\Delta L^* = L^*_{\text{cheeks}} - L^*_{\text{underEyes}}$ and discoloration $\Delta b^*$.
- Marked with `isBeta: true`, confidence capped at 0.75; penalized if pitch < -5° (downward tilt creates orbital cast shadows).
- Heatmap: under-eye relative darkening map [0, 255].

## 4. Aggregation & Scoring Pipeline (`packages/analysis-core/src/scoring/`)
- `aggregateAnalysis(results: AnalysisResult[], quality: QualityReport): AggregatedAnalysisResult`
- Computes overall composite skin index (0–100) weighting core concerns.
- Determines top primary concerns.
- Ensures non-diagnostic, strictly cosmetic phrasing.

## 5. Test Plan
- **Synthetic Perturbation Tests** (`tests/analyzers.test.ts`):
  - For each analyzer: create a synthetic baseline face patch and sequentially inject 4 increasing levels of the target feature (redness tint, dark spots, specular shine, high-frequency noise, crease lines, under-eye darkness). Verify scores increase strictly monotonically.
- **Test-Retest Stability**:
  - Run identical inputs with 1% random noise perturbation; verify score variance < 3 points.
- **Cross-Lighting & Quality Robustness**:
  - Verify confidence drops gracefully when lighting evenness or blur degrades.
- **Cancellation**:
  - Verify `AbortSignal` interrupts analysis cleanly without hanging.
- **Worker & Performance**:
  - Worker execution of all 6 analyzers runs in < 500 ms on test fixtures (well within 3–4 s budget).
