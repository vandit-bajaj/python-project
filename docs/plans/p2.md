# Phase 2 Plan: Face Geometry and Region Engine

- **Phase**: 2 — Face geometry and region engine
- **Author**: Lead Engineer
- **Status**: Pre-approved (conforms to Roadmap §9 Phase 2 and rules 00–70)

---

## 1. Objectives & Scope
Establish the mathematical and geometric foundation for all subsequent skin analyzers. From a captured face, produce:
1. Stable 8-region facial partitions (forehead, left/right cheeks, nose, chin, perioral, under-eyes, T-zone, U-zone).
2. Clean morphological skin mask excluding eyes, eyebrows, lips, and nostrils.
3. Iris-based scale normalisation (pixels to approximate millimetres).
4. Accurate sRGB to CIELAB color space transformation pipeline.
5. Typed Web Worker boundary via Comlink to keep all heavy geometry processing off the main UI thread.
6. A dev-only visualizer at `/debug/regions`.

---

## 2. Tasks & Deliverables

### A. Pure Geometry & Regions Engine (`packages/analysis-core`)
1. **Landmark Subsets & Regions** (`src/geometry/landmarks.ts`):
   - Canonical 478-point MediaPipe landmark index groups for facial regions, eyes, lips, and irises.
2. **Iris Scale Normalization** (`src/geometry/scale.ts`):
   - Derives metric scale (`pixelsPerMm`) based on anatomical average iris diameter (11.7 mm) from iris landmarks.
3. **Skin Mask Generator** (`src/geometry/mask.ts`):
   - Polygon rasterizer and morphological exclusion: face boundary minus eyes, eyebrows, inner mouth, and nostrils.
4. **Color Conversion Pipeline** (`src/geometry/color.ts`):
   - Pure, optimized sRGB -> Linear RGB -> CIE XYZ (D65) -> CIELAB (`L*`, `a*`, `b*`).
5. **Canonical UV Map Types** (`src/geometry/unwrap.ts`):
   - Data structures for UV-unwrapped face texture representations.

### B. Unit Test Suite (`packages/analysis-core/tests/`)
1. `tests/color.test.ts`: Colorimetry tests verifying CIELAB conversion against standard reference color coordinates (pure black, D65 white, neutral gray, primary red/green).
2. `tests/geometry.test.ts`: Tests for iris scale calculation, region point containment, and skin mask exclusions.

### C. Web Worker & Comlink RPC (`apps/web`)
1. **Worker Contract** (`apps/web/src/workers/vision.worker.ts`):
   - Implements Comlink RPC endpoints for off-main-thread geometry and color analysis.
2. **Worker Client** (`apps/web/src/workers/client.ts`):
   - Typed client wrapper managing worker lifecycle and transferable objects.

### D. Debug Visualizer Screen (`apps/web/src/app/debug/regions/page.tsx`)
- Dev-only interactive inspection tool displaying facial regions, skin mask toggle, and real-time CIELAB color readings.

### E. Verification & E2E
- Playwright E2E tests verifying `/debug/regions` renders correctly with zero outbound requests.

---

## 3. Risk Assessment & Mitigation

| Risk | Impact | Mitigation |
|---|---|---|
| Inaccurate color conversions distorting redness/pigmentation analyzers | Unreliable skin score measurements | Rigorous unit test suite with KaTeX KaTeX/CIELAB reference values for D65 white point |
| Worker message cloning overhead causing UI hitching | Mobile frame rate drops | Use Transferable objects (`ArrayBuffer`, `ImageBitmap`) across worker boundary |
| Landmark coordinate jitter across frames | Fluctuating region scores | Exponential moving average smoothing for live landmarks; single-frame canonicalization for stills |
