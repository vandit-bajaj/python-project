# Phase 5 Plan: Report and Visualisation System

- **Phase**: 5 — Report and visualisation system
- **Author**: Lead Engineer
- **Status**: Pre-approved (conforms to Roadmap §6, §9 Phase 5 and rules 00–70)

---

## 1. Objectives & Scope
Build a minimalist, mobile-first, vertical "story" skin report in `apps/web` (`/report` route) and reusable design components in `packages/ui`.
The report presents on-device analysis results clearly, non-diagnostically, and accessibly across mobile screen sizes (320px to tablet), complete with:
1. **Vertical Story Layout**:
   - Header: Overall composite score (animated SVG ring) + capture quality confidence.
   - Primary Concern Highlights: Top identified cosmetic concerns.
   - Concern Cards: Expandable cards with score, severity band, regional breakdown, plain-language meaning, general care guidance, and when to see a dermatologist.
   - Interactive Heatmap Viewer: Dual canvas/image slider (original photo vs. heatmap overlay) with concern selector chips and perceptually uniform, color-blind-safe heatmap palette.
   - Region Breakdown Map: Regional score chips mapped across facial zones.
   - Capture Quality & Confidence Breakdown: Transparency into lighting, blur, and pose metrics.
   - Methodology & Limitations: Plain-language disclaimer, on-device privacy guarantee, and tone considerations.
   - Actions: Pure client-side PDF export and "Scan Again" button.
2. **Visual System & Accessibility**:
   - Neutral palette + one restrained accent (cosmetic teal-cyan).
   - Perceptually uniform color map (magma / viridis gradient: slate navy -> amber -> coral, avoiding red-only for color-blind safety).
   - Animated SVG score rings respecting `prefers-reduced-motion`.
   - WCAG AA contrast compliance and touch targets ≥ 44px.
3. **Pure Client-Side PDF Export**:
   - Lightweight, dependency-free binary PDF generator (`export/pdf.ts`) generating downloadable PDF reports directly in the browser via Blob URL.
   - Co-exists with print-optimized CSS (`@media print`) for native iOS Safari / Android Chrome print-to-PDF.
4. **Copy & Content Module**:
   - Centralized in `apps/web/src/content/index.ts`.
   - Strictly non-diagnostic cosmetic language: "relative index", "estimated blemishes", "cosmetic insights".

## 2. Component Architecture (`packages/ui` & `apps/web`)

### Reusable UI Primitives (`packages/ui/src/components/`)
- `ScoreRing.tsx`: Accessible SVG radial progress ring with animated stroke-dashoffset, ARIA value attributes, and reduced-motion support.
- `HeatmapCanvas.tsx`: Color-blind-safe false-color rasterizer translating 0–255 heatmap buffers into uniform multi-hue palettes.
- `HeatmapSlider.tsx`: Touch-friendly comparison slider between camera face crop and heatmap overlay.
- `RegionPill.tsx`: Regional score indicator chips.

### Report View (`apps/web/src/app/report/page.tsx`)
- Reads aggregated analysis from client state (or generates live demo sample if accessed directly).
- Renders the complete vertical story sequence.
- Optimized for 390×844 (iOS) and 360×800 (Android) mobile viewports with safe-area insets.

### Client-Side PDF Generation (`apps/web/src/utils/pdf.ts`)
- Pure in-browser PDF 1.4 binary emitter:
  - Header: DermaLens report title, timestamp, overall score.
  - Quality metrics & confidence rating.
  - Concern breakdown table with regional scores and severity bands.
  - Legal disclaimer & limitations text.
  - Triggered via `downloadReportPdf()`. Zero external npm dependencies.

## 3. Test & Verification Plan
- **Unit Tests** (`packages/ui/tests/` or `packages/analysis-core/tests/`):
  - Verify PDF byte generation emits valid `%PDF-1.4` binary structure with valid trailer and cross-reference table.

- **Playwright Mobile E2E** (`apps/web/e2e/report.spec.ts`):
  - Verify vertical story layout loads cleanly at 390×844 and 360×800.
  - Verify interactive heatmap slider and concern toggles.
  - Verify concern cards expand and reveal care guidance.
  - Verify PDF export button triggers download or print action.
  - Verify zero external outbound requests.
