# Phase 8 Plan — Hardening, Transparency & Launch Readiness

## Overview
Phase 8 hardens DermaLens for public v1.0 release: comprehensive accessibility pass, global error boundaries and failure recovery, dedicated transparency and legal pages (`/how-it-measures`, `/privacy`, `/terms`), SEO metadata with pre-launch `noindex` management, bundle optimization, and complete verification across the mobile matrix leading to Milestone 5.

---

## Scope & Tasks

### 1. Reliability & Error Recovery
- [x] Next.js Error Boundaries: `apps/web/src/app/error.tsx` and `apps/web/src/app/global-error.tsx` with user-friendly retry and return-to-safety actions.
- [x] Worker & Hardware Error Recovery: Graceful fallback when WebGL, MediaDevices, or Web Workers encounter browser restrictions or runtime faults.
- [x] Storage quota exhaustion recovery.

### 2. Accessibility (a11y) & UX Hardening
- [x] Skip link (`Skip to main content`) on all layouts.
- [x] Minimum 44x44px touch target validation across all buttons, chips, and toggles.
- [x] Complete ARIA landmarks, `role` attributes, `aria-expanded`, and keyboard tab indexing.
- [x] Respect `prefers-reduced-motion` in all CSS animations, `ScoreRing` sweeps, and Three.js 3D viewer.

### 3. Legal, Consent & Transparency Pages
- [x] `/how-it-measures`: Deep-dive into classical CV algorithms, iris px/mm scale reference, Fitzpatrick skin tone considerations, and limitations.
- [x] `/privacy`: Clear plain-language declaration of 100% on-device architecture, zero network egress, zero cookies, zero third-party telemetry, and complete local data erasure controls.
- [x] `/terms`: Terms of use emphasizing non-diagnostic, cosmetic wellness scope and dermatologist consultation thresholds.

### 4. Metadata & SEO Infrastructure
- [x] Dynamic metadata (`layout.tsx`), OpenGraph cards, favicons.
- [x] `robots.ts` and `sitemap.ts` enforcing `noindex` pre-launch (D13) until launch domain cutover.

### 5. Final Verification & Milestone Gate
- [x] Full test pass: Typecheck, Biome lint, Unit tests, Turbo build, Playwright mobile E2E suite across all routes.
- [x] Zero external outbound requests audit.
- [x] Bundle budget audit (< 150 KB initial JS).
- [x] Prepare Milestone 5 Report (`docs/reports/M5.md`).
