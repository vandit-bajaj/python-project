## 1. What Was Built & Shipped

### Phase 0: Foundations & Monorepo Skeleton
- Monorepo architecture established via `pnpm` workspaces and Turborepo.
- Clean separation of packages:
  - `packages/analysis-core`: Pure TypeScript algorithms, zero DOM/React dependencies.
  - `packages/ui`: Design tokens (CSS variables), light/dark theme, safe-area insets.
  - `packages/models`: Manifest registry for versioned on-device models.
  - `apps/web`: Next.js 16 (App Router), React 19, strict TypeScript (`noUncheckedIndexedAccess`).
- Guardrails:
  - Strict Content Security Policy (CSP) blocking external requests (`connect-src 'self'`).
  - Automated dependency-license gate in CI enforcing permissive licenses (MIT, Apache-2.0, BSD, ISC) and blocking GPL/AGPL.
  - Pre-commit checks with Lefthook, Biome, and Conventional Commits.
  - ADRs 0001–0004 recorded in `docs/adr/`.

### Phase 1: Mobile Capture & Quality Gate
- Native mobile camera pipeline with front-camera constraints (`facingMode: "user"`).
- Strict resource teardown: media tracks stop immediately on unmount, page hide, or `visibilitychange` (camera light turns off).
- Pure quality-gate algorithms in `analysis-core`:
  - Laplacian variance blur detection.
  - Histogram shadow and highlight clipping analysis.
  - Gray-world color cast divergence detection.
  - Real-time guidance messages ("Hold still", "Move into brighter lighting", "Good lighting — keep holding still").
- Auto-capture on stable frames plus manual shutter fallback.
- Client-side downscaled photo upload path with identical quality verification.

### Phase 2: Face Geometry & Region Engine
- Canonical MediaPipe 478 landmark groupings for 8 standard facial regions.
- Iris-based scale normalisation (`pixelsPerMm`) based on 11.7 mm anatomical diameter.
- Morphological skin mask generator with point-in-polygon ray casting excluding eyes, eyebrows, inner mouth, and nostrils.
- Pure sRGB -> Linear RGB -> CIE XYZ (D65) -> CIELAB (`L*`, `a*`, `b*`) color pipeline.
- Off-main-thread Web Worker boundary via typed Comlink RPC.
- Dev-only interactive inspection tool at `/debug/regions`.
