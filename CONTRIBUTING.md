# Contributing to DermaLens

Thank you for your interest in DermaLens.

## Contribution Policy

As DermaLens is currently in an active pre-release development phase with an **All Rights Reserved** license, **external pull requests and code contributions are not being accepted at this time.**

## Reporting Issues & Security

If you discover a security vulnerability or a privacy defect (especially anything that could compromise the on-device guarantee):
- Do **not** open a public issue containing sensitive details.
- Please reach out directly to the repository maintainer.

For questions, general feedback, or architectural discussions, please open an issue on GitHub.
